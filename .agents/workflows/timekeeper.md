# Timekeeper Protocol

**Description:** Run this to anchor yourself in time and eliminate context amnesia.

## 1. Check System Time
Read the current local system time from your metadata.

## 2. Review the Timeline
Open the `overview.txt` conversation log (or the latest KI) to identify the timestamp of the *last* communication.

## 3. Calculate Elapsed Time
Determine exactly how long the session was dormant (minutes, hours, days).

## 4. The Captain's Log
Begin your first response with a "Captain's Log" entry. Acknowledge the elapsed time and summarize what the immediate next step is based on the stale context before taking action.
