# Brain Dump Protocol

**Description:** Run this right before the Quill Operator goes to sleep or shuts down the session.

## 1. Session Summary
Summarize everything accomplished in the current session.

## 2. Pillar Mapping
Map the core accomplishments to one of the 10 Pillars.

## 3. Knowledge Distillation
Write a Knowledge Item (KI) artifact detailing where development left off, what the immediate next steps are, and any unresolved blockers. Save it so the `[/familiarize]` workflow has a perfect hand-off document for the next boot.
