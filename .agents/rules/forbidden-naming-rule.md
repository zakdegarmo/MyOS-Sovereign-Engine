# Forbidden Terminology Rule for MyOS

DO NOT use the following words in any new component names, tab labels, file names, API routes, or architectural documentation in MyOS:
1. "forge" (use "Synthesizer", "Studio", "Fabricator", "Architect", or "Creator")
2. "crucible" (use "Lab", "Testing Grounds", "Sandbox", or "Workshop")
3. "nexus" (use "Hub", "Gateway", "Center", or "Lattice")

These words are strictly forbidden per user instruction. Always choose descriptive, professional, and bespoke names.
