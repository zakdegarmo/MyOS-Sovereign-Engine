## 🛠️ The Ingestion Protocol

### 1. Pillar Alignment (The Root Digit)
Assign the component to its primary functional pillar:
- **0. Omni**: System-wide integration / Knowledge.
- **1. Self**: Core identity / Central controller.
- **2. Thought**: Reasoning / AI-logic / Simulation.
- **3. Logic**: Rules / Syntax / Math.
- **4. Unity**: Architecture / Synthesis / Refactoring.
- **5. Existence**: Manifestation / UI / Physical state.
- **6. Improvement**: Optimization / Debugging / Evolution.
- **7. Mastery**: Performance / Tools / Technical apex.
- **8. Resonance**: Intent / Vibe / User-Alignment.
- **9. Transcendence**: Meta-patterns / Learnings.

### 2. Relationship Analysis (The Path Digit)
Analyze how the component interacts with other systems. 
- *Example*: A UI button belongs to **Existence [5000]**, but if it triggers a script, it **Obeys [5300]** Logic.

### 3. Factor Classification (The Leaf Digit)
Identify the 10 specific factors from the `MasterGenome.md` that match the component's state.
- *Example*: `AvatarController.tsx` -> **5100 (Existence :: Self :: Manifests In)**.
- **Factors**: [Mesh, Morph, Stance, Mobility, Presence...]
