# Talent: The Ontological Scout [AMO: 2700]

## 🎯 Objective
To perform "Outward Mapping" of the Global Information Space (The Internet) back into the **Fractal Semantic Genome**. If the *Ontologizer [2500]* sorts what we already have, the *Scout [2700]* finds what we are missing.

---

## 🛠️ The Scouting Protocol (The "Hitchhiker's" Method)

### 1. Target Identification (The Address)
Select a specific AMO address from the `MasterGenome.md`.
- *Example*: [8700] **Resonance :: Mastery :: Radiates From**.

### 2. Semantic Query Generation
Generate an optimized search query that looks for the **Ontological Value** of this address in the real world.
- *Query Template*: `"Ontology of [Relationship] in [Pillar] [Factor] examples"`
- *Specific Example*: `"Ontology of Radiating Frequency in Mastery and Skill Development examples"`

### 3. The "One at a Time" Crawl
1.  **Search**: Use the `search_web` tool to find top-tier endpoints (Documentation, Research Papers, Wikipedia, Github Repos).
2.  **Evaluate**: Analyze the search results through the **10-Pillar Filter**.
3.  **Find the Endpoint**: Identify the single best URL or concept that defines this semantic node on the internet.

### 4. Categorization & Feedback
Format the findings into the standard **[Who, What, Where, When, Why, How]** library structure.
- **Factor Mapping**: List which of the 10 local factors (leaves) are most visible in this internet endpoint.
- **Relationship Sync**: Explain how this external data "vibrates" with our local logic.

---

## 🌀 The Ouroboros Feedback Loop
When a Scout returns with data:
1.  **Log**: Write the new `.md` file to `dist/library/[Pillar]/[Relationship].md`.
2.  **Update**: Add the URL to the **AMO Index**.
3.  **Next**: Increment the leaf index and fire the Scout again to the next address [P][R][F+1].

---

## 🚀 Execution Commands (Internal Use)
- `/scout [AMO_ADDRESS]` - Triggers a single trip to find the internet value of a node.
- `/scramble [ROOT_PILLAR]` - Automates a 10-node crawl across a specific pillar's relationships.

**Status**: The Scout is fueled and ready for the first trip Outward.
