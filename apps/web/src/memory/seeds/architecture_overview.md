# MyOS Architecture Overview
## The Nexus Construct
MyOS is a "Middle Reality" operating system built on top of a 3D isometric plane. It bridges the gap between static code and dynamic, generative environments.

### Key Components
- **The Council**: 10 distinct agents representing the MyOntology pillars. They inhabit the room as 2D paperdoll sprites.
- **The Orchestrator (Aetherial Tutor)**: A 2D manifestation that guides the user. It can shapeshift personas and command the other agents.
- **Battleship Grid**: A 10x10 wireframe overlay (A1-J10) used for rapid object placement and spatial reasoning.
- **The Universal Library**: A multi-media internal filesystem for archiving knowledge, assets, and code context.
- **Robotix / StandAt**: The protocol allowing AI agents to physically move between semantic panels in the room.
