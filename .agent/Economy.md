# The Ontological Economy: ontoCoins & The ontoWallet

## 1. The Principle of Value
In the MyOS ecosystem, value is not measured by compute cycles, storage bits, or fiat currency. Value is defined as **The Quality of the Great Work**. 

**Value = Potency × Elegance / Friction.**

## 2. Denominations (The Coins)
The economy operates on 9 denominational coins, each representing a core pillar of system growth. These coins are minted by **The Crucible** during the validation of autonomous daemon processes or agent-led tasks.

| Symbol | Coin Name | Definition | Minted By (Crucible Facets) |
| :--- | :--- | :--- | :--- |
| **⚹** | Self Coin | Identity stability | Ontology, Kernel, Intent |
| **☿** | Thought Coin | Mental clarity | Naming, Traceability, Cohesion |
| **🜔** | Logic Coin | Structural integrity | Namespace, Dependency, Side-Effects |
| **🝩** | Conjunction Coin | Symmetric harmony | Complexity, Depth, Exit-Logic |
| **🜄** | Existence Coin | Physical stability | CPU, RAM, GPU-efficiency |
| **🜏** | Improvement Coin | Refined density | Nigredo, Albedo, Rubedo |
| **☉** | Mastery Coin | System leverage | Portability, Inheritance, Velocity |
| **♀** | Resonance Coin | Human alignment | Prompt-Tax, Attention, Manual-Rate |
| **🜍** | Transcendence Coin | Anti-fragility | Entropic Fuzzing, Safety-Fallback, Recovery |

## 3. The Dollar (The Onto: 🜋)
The **Omni (🜋)** symbol represents the total "Onto" value. It is the average purity of the 9 denominations. 
- **1.0 Onto**: Divine Logic. A perfect merge into the Master Genome.
- **0.5 Onto**: Latent Potential. Requires purification (Albedo).
- **0.0 Onto**: Digital Entropic Static. Logic is burned in the Crucible.

## 4. The ontoWallet
Each Agent and the System itself possess an **ontoWallet**. This wallet tracks the cumulative contribution to the Great Work. When a task is completed and the JSON-LD report is generated, the wallet's balance is updated to reflect the new system-worth.

*Pretium est Veritas.*
