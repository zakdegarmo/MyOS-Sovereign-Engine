# 🏰 MyOS Sovereign Engine

> **Modern 2.5D/3D WebGL Agentic OS & Spatial Memory Engine**

Repository: [https://github.com/zakdegarmo/MyOS-Sovereign-Engine](https://github.com/zakdegarmo/MyOS-Sovereign-Engine)

---

## 🌟 Key Subsystems

- 🧠 **SpatialMemoryBridge**: 4D Spatiotemporal State Vector Bridge `[X, Y, Z, DR]` coupling 3D WebGL canvas coordinates 1-to-1 with semantic memory nodes.
- 🌌 **Parallaxatron Engine**: Multiplane Cyclotronic Parallax and special effects engine (Also published as standalone library `@myos/parallaxatron`).
- 🥋 **LPC Equipment Paperdoll Compositor**: Dynamic 2.5D equipment layering engine for 64x64 LPC sprite sheets.
- 🎲 **5e Tactical Encounter Engine**: Turn-based D&D 5e initiative sorting, D20 combat resolution, spell slot management, and encounter logs.
